Narrow viewports: topbar collapses tray to essentials (bell + avatar). Sub-tabs move below content area or become horizontal scroll within the extension's content zone. Tray popovers become bottom sheets. Float panels become full-screen modals with back button (same as current shell doc §3.5). The panel component doesn't know the viewport — the shell adapts the container.
