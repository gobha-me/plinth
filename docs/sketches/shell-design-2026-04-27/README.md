# Shell design archive — 2026-04-27

This directory preserves the visual prototypes that informed Plinth's frontend
shell contracts. The HTML and JSX are design references, not production source
and not supported standalone applications.

All people, organizations, clients, credentials, storage locations, events,
and operational data shown in these files are fictional examples. They do not
describe a deployed Plinth instance.

The primary prototype is `project/Plinth Shell.html`. Its files under
`project/shell/` demonstrate layout, visual states, and integration-point names.
Production implementations must follow the current architecture and ICD files
when a prototype differs from a ratified contract.
