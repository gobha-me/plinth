# Public history

Plinth's public Git history begins with version 0.6.3. Earlier development was
performed in private repositories. That private history is retained by the
maintainer for provenance and recovery but is not part of the public project.

`docs/CHANGELOG.md` preserves the technical chronology of that earlier work.
Pre-public branch names and milestones in the changelog are historical labels;
they are not expected to resolve to public Git refs or pull requests.

The public root was created only after a full-ref secret scan, license review,
privacy pass, deterministic shutdown repair, and exact-SHA CI validation. New
changes use public topic branches and pull requests.
