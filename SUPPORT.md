# Support

Use GitHub issues for reproducible bugs and focused feature proposals. Include
the Plinth version, operating system, compiler, database version, expected
behavior, actual behavior, and a minimal reproduction with secrets removed.

This is a community-maintained pre-1.0 project without guaranteed response
times. Questions about deploying unreviewed configurations on public networks
may be closed in favor of the security and configuration documentation.

Security vulnerabilities must be reported privately through GitHub as described
in `SECURITY.md`, never through a public issue.
